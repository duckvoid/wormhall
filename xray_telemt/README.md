# Haproxy+Caddy+Telemt+Xray
Рабочий пример конфигурации связки

## Описание
В текущем примере haproxy выступает в качестве фронта, который маршрутизирует трафик по SNI, что позволяет освободить 
основные порты и размещать больше сервисов помимо прокси. Caddy выступает в роли фронта с заглушкой, а также берет на себя
работую с сертификатами. Telemt, в свою очередь, использует либо локальный прокси xray, либо фронт с заглушкой

По итогу цепочка такая

## Настройка
Пожалуйста, внимательно ознакомьтесь со всеми конфигами и замените данные на свои!

В текущем примере вся адресация осуществляется по статическим адресам внутри docker сети. Это связано с тем, что
telemt и haproxy неадекватно работают с резовингом имен

Перед запуском нужно вручную инициировать общие сеть и volume

Также в папке xray лежит скрипт-фикс syn/ack

```shell
sudo docker network create -d bridge --subnet=172.100.100.0/24 xray-net
sudo docker volume create caddy_data
```
